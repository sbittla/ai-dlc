## Brief

Relay's non-production environment is designed for AWS (Lab 11.1). A customer asks whether Relay could run on Azure or Google Cloud, and a manager asks which would be cheapest. Both questions have answers that look easy and are not: a table of service names hides the differences that change a design, and a cost comparison depends on assumptions that are rarely written down.

You have a structured mapping of sixteen concerns, from the account boundary to the IaC provider, each with its AWS, Azure and GCP service, how close they are, and the differences by dimension: identity, networking, quotas, pricing, guardrails and data (`data/mapping.json`). You also have an agent's first draft of a mapping (`data/mapping-draft.json`), Relay's environment described provider-neutrally (`data/workload.json`), and three dated price tables (`data/prices/`). **Every price is an assumption** dated 2026-11-10, and every service name is marked for verification.

**A note on names.** `data/mapping.json` keeps the names "Azure OpenAI" and "Vertex AI". As of November 2026, Microsoft offers Azure OpenAI within Microsoft Foundry (formerly Azure AI Foundry). Google's release notes record that Vertex AI became part of Gemini Enterprise Agent Platform on 22 April 2026. See Appendix D, "A note on names", and Appendix F, entry F-L05.

## What you will practise

- Writing a **service mapping** that records real differences, not only names, and checking it mechanically.
- Comparing **pricing models**: per-hour against per-second billing, free grants, per-zone against per-endpoint charges, and what a standby costs on each provider.
- Showing how one **requirement** (a database standby) and one **schedule** (working hours only) change a comparison, so that nobody reads a ranking as a fact.

## Troubleshooting

| Symptom | Likely cause |
| --- | --- |
| Azure containers come out at about $102 or $118, not $112.86 | You applied the free grant per container, or not at all; it applies once, to the total. |
| GCP private endpoints are not zero | Its table's billing is `"none"`: Private Google Access has no hourly charge. |
| The AWS total is not $221.90 | Interface endpoints bill per service per zone: 5 x 2 x $0.01 x 730. |
| `schedule` changes the worker | Only containers with `"schedulable": true` change; the worker and proxy run all month. |
