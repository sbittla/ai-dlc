# ADR-001: The AI step proposes; deterministic code decides and acts

Status: accepted
Date: 2027-08-02
Decided by: k.ade
Reviewed by: k.bo, k.cy

## Context

The deterministic flow must work without the model.

## Options considered

- A: model decides routes
- B: model proposes, code decides

## Decision

Option B.

## Consequences

A slow or wrong model falls back to the rule route.

## Rejected alternatives

### Option A

Rejected: a steered model could reroute escalations.
